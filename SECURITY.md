# Security policy

Please report vulnerabilities in ShipReady (the CLI, the GitHub Action or the npm launcher) privately through GitHub: open the [Security tab](https://github.com/Shipmate-agency/shipready/security) of this repository and choose **Report a vulnerability**. Do not open a public issue.

A missed detection or a false positive is not a vulnerability; open a normal issue for those.

Only the latest release is supported.
